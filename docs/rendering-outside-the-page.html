Rendering a sheet outside the page

The page composes its sheet as SVG in the browser and nothing commits a raster, so a picture of a sheet is made on demand.

node tools/cheatsheet.mjs --generate <slug> --format webp

It composes and renders through the same layer the page does, which then takes one of two routes - a real engine, which draws the face the design language measured, or the drawing surface's own dependency free rasterizer, which draws a built in single stroke alphabet. It reports which one answered, because a file that does not say that cannot be reviewed against the design language.

The flags

FlagWhat it does
--theme, --layout Each takes the one name the record supports or a path to a JSON model of its own. A --theme file may be partial.
--data-only Emits the document and what the composition chose without rendering anything.
--list Names what there is.
--document <path> Reads a JSON document from anywhere in place of a slug.
--help The rest.

A sheet does not have to be in the catalog

--document <path> reads a JSON document from anywhere in place of a slug, so the command is an entry point for a document rather than for this repository's own index. It reports the same fields either way, with source saying which flag named the sheet.
