Acme Corp Handbook

Check one folder

One argument, and the folder is read in place. Nothing is written.

demo-app check ./records

Declare what a record must carry

A schema is a plain object. Every field names a type, and a field left out of the schema is a field the check ignores. 

const schema = {
  id: "string",
  opened: "date",
  owner: "email",
  total: "number",
};

Read the report rather than the exit code

The exit code says whether anything failed. The report says what, which is the half worth reading in a terminal. 

const report = await check("./records", schema);
for (const failure of report.failures) {
  console.log(`${failure.record}: ${failure.field} ${failure.why}`);
}

Two flags, and when each is worth it

--quiet prints the failures and nothing else, which is what a scheduled run wants. --json prints the report as data, for anything that reads it rather than looks at it. 

demo-app check ./records --quiet
demo-app check ./records --json > report.json
