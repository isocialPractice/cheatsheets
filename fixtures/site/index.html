What demo-app does

demo-app reads a folder of records, checks each against the schema it declares, and writes a report. It installs nothing and reads nothing but the folder it is pointed at.

The three words worth knowing

Record
One file in the folder, holding one subject.
Schema
The fields a record must carry, and what each one may hold.
Report
What came back: the records that passed, and the field that failed on each that did not.

Where to go next

Start with the tutorial if you have a folder of records already. Read the configuration pages first if you are deciding whether the schema can say what your records need.
