Where the options are read from

config/reports.json beside the records folder, where there is one. Every option has a default, so a folder with no configuration file is a folder that reads with the defaults rather than one that refuses.

Options
OptionDefaultWhat it decides
folder./recordsWhich folder is read
schema./schema.jsonWhich fields a record must carry
outputDir./reportsWhere a written report lands
strictfalseWhether a field the schema does not name is a failure
localeenHow a date in a record is read

The one option worth setting deliberately

strict decides what an unknown field means. Left off, a record may carry anything the schema does not name; turned on, it may not - which is what a folder that several tools write into wants, and what a folder a person maintains by hand almost never does.
