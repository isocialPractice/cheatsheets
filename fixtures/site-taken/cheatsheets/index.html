Our cheatsheets

This folder is ours. It was here before the tool was run against this site, it is not generated, and nothing in it carries a marking - the crawl never descends into a folder of this name, so these words are not collected onto anything.

What a run does with it is resolve past it: the ladder tries cheatsheets/, finds this folder, and writes into cheatsheets/cheatsheets/ instead. This file is byte for byte what it was afterwards, which is the claim the variant exists to hold.
